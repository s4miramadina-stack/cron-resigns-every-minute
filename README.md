The one-line resignation letter of a cron job that cannot stop doing things on schedule, not even quitting. `main.py` writes the letter (at most 140 characters) to `/output/entry.txt` and exits non-zero if it would be empty or too long.

## Run it

```sh
python3 main.py
```
